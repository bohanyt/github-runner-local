# github-runner-local

A Windows wizard for connecting a locally owned PC to GitHub Actions as a self-hosted runner, with a planned request/result bridge for chat agents.

**Status: BOOTSTRAPPING / DESIGN ONLY. There is no installable application or release yet.**

The public repository distributes product source and documentation. It is **not** a public execution mailbox, and no laptop runner should be registered here during planning.

Start with `AGENTS.md` and `docs/CURRENT.md` once the bootstrap publication is complete. Coordination is in [Issue #1](https://github.com/bohanyt/github-runner-local/issues/1); independent planning is in [Issue #2](https://github.com/bohanyt/github-runner-local/issues/2).

No hosted Actions workflows, live runner jobs, OAuth registrations, credentials, installers, or machine changes are part of this bootstrap.

This is an independent project, not an official GitHub or OpenAI product. License selection is pending owner approval.
