# Contributing

Read AGENTS.md and main docs/CURRENT.md first. The current phase is planning; production work and live workflow changes are not yet assigned.

Keep proposals in a task DRAFT PR. Include acceptance criteria and evidence, not just code. Never include credentials, downloaded runner state, actual job workspaces or private project output. Public distribution and execution scope are separate concerns.

No hosted Actions validation runs during this phase. The selected rough-design branch includes a small local checker; run it in temporary compute and disclose its scope. It checks documents/examples only, not Windows installation or runner safety.

License choice is pending owner decision. Do not import third-party code, logos or license assumptions without documenting provenance and compatibility.
