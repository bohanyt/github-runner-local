Step 5 / Mode & permissions

Admin only when it is needed.

Normal sign-in and UI stay non-admin. A bounded setup helper may request Windows UAC for an approved service operation.

Manual / portable

Proposed first mode

Runner is active while its process and user session remain running. Same-user jobs can access that user's files and credentials.

Windows service

Design gate

Protected service/helper files and a non-admin job identity must be resolved. This may require approved paths outside Documents.

A blocked shell or executable remains blocked even when the wizard opens or UAC succeeds. No security-policy bypass.
